선택 영역 보정
누끼 작업

누끼 선택 방식
자동 선택은 사진 가장자리의 배경색을 기준으로 배경 후보를 분리합니다. 단색·대비가 뚜렷한 배경에서 가장 잘 작동하며, 복잡한 머리카락이나 비슷한 색의 배경은 수동으로 다듬어 주세요.
선택은 기본적으로 누적됩니다. 수동 터치는 색상으로 이어진 영역을 더하고, 올가미는 피사체 둘레를 여유 있게 그리면 테두리와 연결된 배경을 색상 경계로 추정해 제거한 뒤 추가합니다. 복잡한 머리카락·배경과 피사체 색이 비슷한 사진은 결과를 확대해 확인하세요. 새로 시작하려면 ‘선택 초기화’를 누르세요.
사진을 연 뒤 자동 선택 또는 수동 선택을 고르세요.
수동 라이팅 · 로컬 처리
사진 위에 광원을 합성합니다. 위치·크기·방향·색상·강도를 조절하세요. 수동 합성 기능이며 AI 피사체 인식은 아닙니다.
체크하면 현재 마스크 안에서만 라이팅이 적용됩니다.
사진을 열고 조명 값을 조절하세요.
부분 보정 대상 선택
이 기능은 누끼 제거가 아닙니다. 사진은 그대로 두고 선택한 하늘·인물·배경만 부분 보정하기 위한 선택 영역입니다.
비슷한 색의 엉뚱한 부분이 포함되면 ‘선택에서 빼기’를 켜고 그 부분을 터치하거나 올가미로 제외하세요. 다시 누르면 선택 추가 모드입니다.
하늘 선택
사진 상단의 색상과 연결된 영역을 빠르게 선택합니다.
인물 선택
인물 전체를 AI로 인식하는 모델은 아직 연결되어 있지 않습니다. 인물의 여러 지점에서 색상 영역을 누적 선택하거나 올가미로 대략 둘러싼 뒤 다듬으세요.
배경 선택
배경은 색상 범위로 선택하거나 올가미로 영역을 지정하세요. 선택은 누끼 마스크와 완전히 분리되어 저장됩니다.
색상 범위 선택
하늘·물·벽 등 비슷한 색상으로 이루어진 영역을 선택합니다.
영역 그리기 · 적용
선택한 영역을 마스크에 적용하면 노출·채도·색상 등 부분 보정을 할 수 있습니다. 투명 배경이나 누끼 결과에는 영향을 주지 않습니다.
선택 영역 색상·빛 보정
선택 중 아래 값을 바꾸면 중앙 사진에 즉시 미리보기됩니다. 다른 메뉴로 이동하거나 화면을 스크롤해도 선택 영역과 미리보기 값을 유지합니다. 적용 후에는 해당 대상의 마스크에 저장됩니다.
선택 정밀도
선택 범위와 가장자리 부드러움을 조절하세요. 선택한 영역은 현재 마스크 레이어에 적용됩니다. 레이어와 브러시·원형·타원형·그라데이션 도구는 마스크 메뉴에서 관리합니다.
선택 상태
사진을 연 뒤 보정할 대상을 선택하세요.
선택 영역 보정
선택한 대상의 마스크 레이어를 보정하세요. 마스크 메뉴에서 레이어를 고른 뒤 영역 노출·채도 등의 값을 조절할 수 있습니다.

보정 목표
